Tents 0.1.0 is the first portable build of the M1 MVP. Your desktop items live in tents: containers drawn behind every window on the desktop.

> **Early release.** It has been run on one Windows 11 machine. Most of the [manual test matrix](https://github.com/alicesore/tents/blob/v0.1.0/docs/manual-test-matrix.md) has not been run yet, and Windows 10 22H2 is untested.

## What it does

- **Every desktop item is in a tent.** Items you have not assigned go to the default "Desktop" tent.
  - Icons and thumbnails come from the shell.
  - These work as they do on the desktop: opening items, the shell's context menu, drag and drop to and from Explorer, and new, renamed and deleted files.
- **You arrange the tents.** Move, resize, roll up to the title bar, create, rename and delete. Deleting a tent moves its items back to "Desktop"; no file is touched.
- **The layout is kept** in `%APPDATA%\Tents\layout.json` and restored at the next start, including after an Explorer restart.
- **The native desktop icons are off** while Tents shows your items.
  - They come back when you pause or exit: use the tray icon's **Show Windows desktop icons** to pause, or **Exit Tents**.
  - If Tents is killed, a small watchdog process turns the icons back on. If both are killed, the next start of Tents does it, or right-click the desktop and choose View > Show desktop icons.
  - Start Tents with `--keep-native-icons` to leave the native icons on.
- **Tray menu:** New tent, Show Windows desktop icons, Start with Windows, Exit.

## Idle numbers

Measured with `bench/IdleCheck/idle-check.ps1` on the `Tents.exe` in this release's zip:
- **Setup:** 10 tents and 200 items, measured 30 s after start over 60 s.
- **Machine:** Windows 11 (build 26300), Ryzen 7 5700X3D, .NET 10 Desktop Runtime, software rendering.

| Metric | Idle | After a resize | Budget |
|---|---|---|---|
| Warm startup (median of 5) | 646 ms | | at most 1000 ms |
| CPU per 60 s | 0 ms | 0 ms | below 16 ms |
| Wakeups per 60 s | 4.8 | 2.9 | at most 5 |
| Working set | 116.9 MB | 123.2 MB | at most 130 MB |
| Private working set | 33.1 MB | 34.4 MB | at most 45 MB |
| Private bytes | 55.8 MB | 59.8 MB | at most 80 MB |
| GCs, timers, thread-pool work items | 0, 0, 0 | 0, 0, 0 | 0, 0, 0 |

**About these numbers:**
- **Budgets:** they come from the project plan. In M1, the working-set budget went from 120 to 130 MB, because most of the working set is shared DLL code. The private memory budgets did not change.
- **"After a resize":** one tent was grown to 984 × 1224 px and shrunk back, then measured the same way.
- **Wakeups:** these are per-thread context-switch counts, not yet confirmed with WPR.
  - The idle window's 4.8 includes 2 on a runtime thread that exited during the window. The later window, with no thread exiting, had 2.9.

## Download and run

1. Install the **.NET 10 Desktop Runtime (x64)** if you do not have it: https://dotnet.microsoft.com/download/dotnet/10.0
2. Unzip `Tents-0.1.0-win-x64.zip` anywhere and run `Tents.exe`.

The build is framework-dependent and ReadyToRun, with Workstation non-concurrent GC. The zip is not code-signed, so Windows SmartScreen may warn the first time you start it.

SHA-256 of `Tents-0.1.0-win-x64.zip`: `8bf0fc94a706a4d21b67dea10fe875c77cb4d28463475119f5ccd9853b6bb9c3`

## Known limits

- Windows 10 22H2 is untested.
- There is no settings window yet (the tray's Settings item is greyed out).
- You can't rename a desktop item in place yet; use Explorer.
- Layouts are not kept per monitor setup yet. A tent left on an unplugged monitor is moved to the primary monitor at the next start.
- Tents have no high-contrast colors and no screen-reader support yet.
